# 📊 E-commerce Order & Return Analysis Dashboard (Excel)

## 📌 Project Overview

This project is an interactive Excel dashboard built to analyze e-commerce orders, returns, customer behavior, and business performance. The dashboard provides key business insights using Pivot Tables, Pivot Charts, KPIs, Timelines, and Slicers.

---

## 🎯 Business Problem

The objective of this project is to help an e-commerce company answer the following questions:

- Which product categories generate the highest revenue?
- Which regions generate the highest sales?
- What is the return rate?
- What are the most common return reasons?
- Which payment methods are most used?
- How do monthly sales and returns change over time?
- Which customer age group places the most orders?

---

## 📂 Dataset

**Source:** Kaggle

## 💡 Key Business Insights

- Electronics generated the highest revenue.
- The overall return rate was approximately 5.5%.
- The 46+ age group placed the highest number of orders.
- Credit Card was the most preferred payment method.
- Returns varied across regions and months.
- Return reasons such as "Not as described" and "Defective" were among the most frequent.
